This is a project that set out to create a bot that played Farkle optimaly. The solution uses value iteration(a solution derived from this paper on solving the dice game pig: https://cs.gettysburg.edu/~tneller/papers/pig.pdf). The directories in the solvers directory are just programs that use value iteration to solve their respetive versions of the game and output a file(this saves on time so the solution only has to be found once) and the game directory contains the actual playable game.
